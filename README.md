## 💼 Featured Projects

Here are some of the key projects I have developed to apply my skills:

### 🏦 [Bank Management System (C++ OOP)](https://github.com/JaafarMaatouk/Bank-Management-System-OOP-cpp.git)

A comprehensive banking system built entirely with Object-Oriented Programming. It features a modular architecture with over 40 classes, managing clients, users, transactions, and currency exchanges. It adheres strictly to the Separation of Concerns principle.

### 🏥 [Hospital Management System (C++ OOP)](https://github.com/JaafarMaatouk/Hospital-Management-System-OOP-cpp.git)

A highly modular system simulating real-world hospital operations. Built using OOP to manage patients, departments, and internal hospital workflows, demonstrating strong inheritance and encapsulation principles.

### 📇 [Contacts Management System (C# 3-Tier)](https://github.com/JaafarMaatouk/Contacts-Management-System-3Tier.git)

A professional desktop application connected to SQL Server. It strictly follows the 3-Tier Architecture (Presentation, Business, and Data Access Layers). It handles full CRUD operations, data validation, and image handling.

### ⚙️ [Custom Data Structures Library (C++)](https://github.com/JaafarMaatouk/Data-Structures-Library-cpp.git)

A custom-built library implementing core data structures from scratch (Doubly Linked Lists, Dynamic Arrays, Stacks, and Queues). It uses C++ Templates to ensure the structures are generic and can handle any data type.

### 🍕 [Pizza Ordering System (C# WinForms)](https://github.com/JaafarMaatouk/Pizza-Ordering-System.git)

A desktop application simulating a restaurant ordering system. It dynamically calculates the total price based on selected sizes, crust types, toppings, and dining options (Eat In or Take Out), demonstrating strong Event-Driven Programming.
